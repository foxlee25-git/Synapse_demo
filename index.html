What Synapse does

把分散的 Agent 工作，变成统一的公司实时状态。

传统企业和小企业开始使用 AI 后，真正的问题不是“有没有 Agent”，而是每个 Agent 做了什么、依赖谁、卡在哪里、是否需要人审批。

Productized prototype

不是项目管理工具，而是公司级 Agent 协调层。

Synapse 站在现有工具之上，连接每个员工自己的 Agent、每个 SaaS、每个项目上下文。它把“谁知道什么”和“谁下一步该做什么”变成实时系统能力。

  • 员工继续使用自己习惯的 Agent 和工具。
  • Agent 通过 MCP、Skill、API 或插件接入公司 OS。
  • 公司 OS 统一感知项目、团队、客户、风险和紧急事项。
  • 敏感动作进入人工审批，自动化执行保留审计链路。

Architecture

五层架构，连接员工 Agent 与企业执行系统。

Employee Agents

员工继续使用自己的 Agent、Copilot、ChatGPT、IDE Agent 或行业助手。

Agent Gateway

通过 MCP、Skill Router、Identity、Permission Policy 和 Context Access 统一接入。

Company OS Core

Work Event Ledger、Context Graph、Risk Engine、Project State Engine、Audit Log 和 Enterprise Memory。

Action Layer

把判断变成任务、消息、审批、写回和跨系统执行，连接 Slack、Docs、CRM、Calendar 和内部系统。
